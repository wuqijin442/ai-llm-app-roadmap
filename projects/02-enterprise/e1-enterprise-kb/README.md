# E1 · 企业级知识库问答（实战）

> 在 `p2` 的 Naive RAG 基础上，做到**企业可交付**：引用来源高亮、混合检索、重排、评测集。
> 适合场景：储能电价政策库、设备手册问答、内部 SOP 检索。

## 相对 p2 的增强点
1. **引用来源**：每条答案标注出自哪篇文档的哪一段，用户可点击/核对（信任与审计）。
2. **混合检索**：向量（语义）+ BM25（关键词）融合，召回更全。
3. **重排（Rerank）**：用 Cross-Encoder 对 top-k 二次精排，准确率显著提升。
4. **评测集**：`eval.json` 存 50 条问答对，每次改策略都跑准确率，量化提升。

## 运行
```bash
pip install langchain langchain-community chromadb rank_bm25 sentence-transformers
python kb.py
```
