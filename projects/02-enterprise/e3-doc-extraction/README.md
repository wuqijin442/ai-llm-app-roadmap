# E3 · 文档结构化抽取（实战）

> 把非结构化文本（合同/工单/发票/设备日志）抽成**结构化 JSON**，供下游系统消费。
> 这是企业高频刚需：比"聊天"更容易量化效果、更容易嵌进现有业务系统。

## 运行
```bash
pip install langchain-ollama
python extract.py
```
把待抽取文本放进 `sample.txt`，或直接在交互里粘贴。

## 你会学到
- 用「JSON 强制输出 + schema 约束」让模型稳定产出可解析结构。
- 抽取后做字段校验（必填项、类型），失败重试/降级。
- 这是把 LLM 接入企业数据流的典型范式（替代正则/规则，泛化更强）。
