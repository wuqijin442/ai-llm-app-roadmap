> 一句话判断：**第 8 期讲「治理底座三根深水桩」（协议 + 记忆 + 引擎），第 9 期讲「AI 基础设施三件套」（算力引擎 + 平台层 + 服务引擎）**——Ray 让 Agent 跑起来（分布式计算）、MLflow 让 Agent 跑明白（实验追踪 + 评测）、TGI 让 Agent 跑得快（推理服务）。后端/前端工程底盘在「算力引擎 + 平台层」杠杆最强（K8s + 分布式 + 系统架构），在「服务引擎」有天然优势（懂后端 + 懂性能 + 懂 API）。
