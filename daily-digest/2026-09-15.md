## 一、市场总盘（为什么「交付与协作层」是第 17 期主线）

- **AI 把前端岗位重新定义到「Agent 落地最前线」（CSDN 2026）**：「前端更多做展示，但 AI Agent、多模态交互的爆发，把前端工程师直接推到了 AI 应用落地的最前线」。三个 2026 实时 JD——**前端 AI 创新应用 P6+ 35–65K（上海/北京，3–5 年，要求『模型调用稳定性、延迟控制、降级策略』）/ AI 前端专家 50–80K×16 薪（80–128 万，5–10 年）/ Agent 前端工程师 40–70K×15 薪（60–105 万，『一年前几乎不存在，现在是大厂争抢的稀缺岗』）**——关键不是「做个 demo」，而是「**集成到生产环境**」：模型调用稳定性 + 延迟控制 + 降级策略，工程能力与 AI 能力缺一不可。
- **「前端+AI」复合溢价约 40%，AI Agent 开发岗同比 +215%（脉脉高聘 2026 春招）**：0–1 年传统开发平均 5,500 元 / AI 方向 18,000 元（差 3.27 倍）；3–5 年传统 22,000 / AI 55,000；**AI Agent 开发岗同比增长 215%，平均月薪 5.5 万，供需比 1:2.5（2.5 个岗抢 1 个人）**；5–10 年资深纯开发岗招聘量同比降 52%、供需比 1:37——企业要的不是「资深纯写代码的人」，而是「能整合 AI、懂业务、扛全链路的人」。
- **GenAI 技能溢价 30–55%，流式 UI 是前端最高溢价项（meritshot H1 2026 印度市场）**：「A frontend developer who can build a chat interface that handles SSE from an LLM, renders streaming markdown without layout shifts, and manages optimistic UI updates for AI actions is commanding a significant premium」。具体：前端 streaming UI + SSE + AI SDK（Vercel AI SDK, LangChain.js）entry ₹10–18 LPA vs 标准 ₹8–12 LPA；全栈能独立交付完整 AI 功能者 senior ₹40–55 LPA。
- **Full-Stack AI Engineer 单独成档 $160K–$250K（Levels.fyi 2026，myengineeringpath.dev）**：Frontend Engineer $110K–$180K / AI Engineer（仅后端）$130K–$220K / **Full-Stack AI Engineer $160K–$250K（供给最低）**——「One person owns the prompt, the retrieval pipeline, the streaming API endpoint, AND the React component. Changes that used to require two engineers, a design review, and a sprint of coordination now happen in a single PR.」前端→AI 工程师只需 9–12 个月（不是 18–24），因为 async 模式 / API 集成 / 状态管理直接迁移，Python 几周可学。
- **Vibe Coding 成 2026 真实岗位簇（vibehackers.io 2026-02 / llmhire.com 2026-04）**：vibehackers 2026-02 报告 **181 个 vibe coding 在招，中位数 $160K**，Microsoft/Google 各 8 个领跑，Cursor 40 mentions（近乎 Claude Code 26 的 2 倍 / Copilot 20），Python(56)/JS(38)/React(36) 最常被要求，**首个「Vibe Coding Specialist」岗位名出现（Dallas 一家 painting company，$50K–250K，用 Lovable + AI agent 生成生产级网站）**；llmhire 2026-04 分析 847 个在招——AI 工具 94% 要求（Claude Code 71% / Cursor 68% / Windsurf 41% / Copilot 38% / Aider 22%），TS 82% / Python 74% / Go 31% / Rust 18%，Next.js/React 77% / Supabase 58% / Docker 44% / Vercel 53%，**remote 78%**。
- **AI 编码工具从好奇变必需（Stack Overflow 2026）**：**76% 专业开发者定期用 AI 编码工具（2023 年 44%）**，从简单补全进化到「一条 prompt 生成完整功能」；GitHub Copilot 参与 40%+ 仓库代码；「vibe coding」= 用自然语言描述需求、AI 生成代码、人转成「审阅/指挥/治理」角色。
- **Design Engineer 是 AI-native 产品团队的「可信产物」角色（Vercel 2026 JD）**：Vercel（v0 / Next.js / AI SDK 背后团队）Design Engineer **$196K–$294K（Senior/Staff，5+ 年）**，职责是「logged-out 体验的最高完成度与交互」——Next.js + Figma + CMS + 动画/性能/可访问性/Core Web Vitals + 增长实验，**并把 v0/generative UI 当主力生产工具**；Adobe Principal Product Designer（GenStudio，要求 vibe coding）最高 $334,500（vibehackers 2026-02）。
- **本期 3 个岗位画像**：
  - **AI 全栈/前端工程师**：把 Agent 输出做成「点得动、看得懂、改得动」的产品——流式 SSE 渲染 + generative UI + 错误/重试/降级，US $160K–$250K 全栈 AI 档 / 国内 Agent 前端 40–70K×15 薪。
  - **Design Engineer（AI-first 设计工程）**：「会写代码的设计师」——用 Next.js + Framer Motion + v0/generative UI 做高完成度交互界面，$196K–$294K（Vercel）。
  - **Vibe Coding / AI-Assisted Software Engineer**：自然语言驱动 AI 生成并迭代代码的人机协作范式——人 review/validate/治理，2026 中位数 $160K / 181 在招 / remote 78%。

> 一句话判断：**前 16 期讲「Agent 背后的系统」（编排/安全/评测/语音/端侧），第 17 期讲「Agent 前面的产品」（谁把它变成用户可用的东西）**——AI 全栈/前端工程师让 Agent 从「API 响应」变成「流式可交互 UI」（US $160K–$250K，因「既懂模型又懂组件」稀缺），Design Engineer 让 Agent 输出从「文本」变成「高完成度界面」（Vercel $196K–$294K，v0/generative UI 当生产工具），Vibe Coding 工程师让「交付软件」从「一人一岗」变成「全栈+AI 单点交付」（中位数 $160K，Meta 2026 把 7000 人转岗 AI / 8000 人裁即此逻辑）。**三者全是「工程底盘 + AI 工具」的直接兑现——本人 EMS 后端（Java/Spring）+ Vue 前端 + 正在补的 Python/AI，正好落在三者的交集上**。
> **Harness 主线**：docs/05 的 6 要素中，第 17 期聚焦「**Interface/IO + Execution（执行）**」两要素的「交付与协作」层——AI 全栈/前端工程师（Interface/IO 的 UI 化：流式渲染 + 客户端错误/重试/降级治理）、Design Engineer（Interface/IO 的「可信产物」化：generative UI 把 Agent 输出变成可交互 UI）、Vibe Coding（Execution 的人机协作形态：AI 写代码 + 人 review/validate/治理）。这是 Harness 从「云端治理（第 9–15 期）」延伸到「**用户侧交付与开发侧协作（第 17 期）**」的标志。

## 三、前沿信号观察（本期新增，不重复既有条目）

- **AI 生成代码的「技术债悬剑」= 审查纪律的刚需（natively.dev 2026 / Fast Company 2025）**：「$1.5 trillion 技术债 by 2027 from AI-generated code」「40%+ junior 承认部署过不完全理解的 AI 代码」「170 issues in 1,645 Lovable apps」——**对转岗者：Vibe Coding 岗位的高薪来自「批判性评估 AI 输出」的能力，不是「用工具快」；本人后端经验（代码审查/调试/安全）正是这个能力的底盘**。

### 关键发现

- **vercel/ai 26,733★** 为「TypeScript AI 应用构建库（AI SDK）」品类标杆（Next.js 团队出品，topics 含 generative-ui / react / vue / svelte），**TypeScript 主语言**——「AI 前端/全栈」从「拼 fetch + 手动流式」升级为「**声明式流式 UI 原语**」（`useChat` / `useCompletion` / 工具调用可视化 + 多 provider 路由），是 AI 全栈/前端工程师岗位的直接基础设施；仓库仅 5 个 .py（B 级几乎无 Python，主语言 TS），测试成本低。
- **e2b-dev/E2B 13,798★** 为「开源安全代码执行沙箱」品类标杆（Apache-2.0，Python 主语言 + 537 .py 全过），**agentic coding 的运行时底座**——Vibe Coding / AI 软件工程 Agent「让 AI 跑真实代码」必须有隔离沙箱（文件系统 + 工具 + 网络可控），E2B 是这一层的开源事实标准（Cursor / 各类 coding agent 的沙箱后端），也是本人「AI 写代码 → 隔离验证 → 再合并」工作流的可复用基础设施。
- **microsoft/TypeChat 8,684★** 为「LLM→结构化数据→UI」品类标杆（MIT，TypeScript 主语言 + 56 .py 全过 + 7 .ipynb 合法），**Design Engineer 的核心桥梁**——用 TypeScript 类型把 LLM 自然语言输出约束为强类型数据结构，让 generative UI 有「可信 schema」而非自由文本，是「Agent 输出→高完成度界面」的质量门控原语（对照 Vercel v0 的端到端生成）。
- **本期 3 仓库的「交付三轴」互补**（本人 EMS 后端视角）：vercel/ai 是「**用户侧交付轴**」（Agent 输出→流式可交互 UI）、TypeChat 是「**产物可信轴**」（LLM 输出→强类型 UI schema）、E2B 是「**开发侧协作轴**」（人+AI 写代码→隔离沙箱验证）——三者合起来 = 「Agent 从模型到用户产品」的完整交付链，直接对应 Harness 的 Interface/IO + Execution 两要素，且全部吃「工程底盘 + AI 工具」而非算法。
- **与既有 61 仓库的衔接**：vercel/ai 与已克隆 `browser-use`（多模态前端）、`dify`（可视化工作流 UI）共同对标「AI 前端交付」；E2B 与已克隆 `All-Hands-AI/OpenHands`（AI 软件工程 Agent）、`huggingface/smolagents`（Agent 框架）共同对标「agentic coding 运行时」；TypeChat 与已克隆 `pydantic`（Agent 工具 I/O 数据契约）共同对标「结构化约束」（TypeChat 偏 UI 层、pydantic 偏工具层）。
