# 2026-08-31 · 每日 AI 岗位学习内容（第 4 期）

> 视角：后端/前端工程师转岗 AI 大模型应用开发。
> 主线：Harness（执行与治理层）+ 工程能力杠杆。
> 本期主线：**「从『写 Agent』到『教 Agent 用、保 Agent 稳、卖 Agent 出去』」**——第 3 期讲「保 / 测 / 架 / 管」四个岗位簇，第 4 期补三块被前三期轻描淡写的拼图：**AI 教育**（把 Agent 教会别人用）、**AI Reliability**（把 Agent 在生产上跑得稳，比 AgentOps 更底层）、**AI GTM**（把 Agent 卖出去，工程化营收链路）。这三块共同构成「AI 应用落地最后一公里」。
> 数据均来自公开招聘平台/行业报告，附来源 URL；未交叉验证的数据单独标注。

## 一、市场总盘（为什么「教育 + 可靠性 + GTM」是第 4 期主线）

- **AI 教育岗位爆发**：67,000+ AI Educator 岗位（LinkedIn 2026-01）、48,000 AI Tutor 岗位 2024–2026 增长 245%；Corporate AI Trainer 薪资 $110,000–$165,000、Director of AI Learning $160,000–$220,000（trendflash.net、aireplacedmyjob.com）。
- **AI Reliability 岗位「独立成类」**：Anthropic 内部团队 **AIRE（AI Reliability Engineering）** 正式存在，Staff 级薪资 $325,000–$485,000（Anthropic Greenhouse 5113224008、simplify.jobs）；NVIDIA / Intuitive Surgical 等已出现「Senior SRE, AI/ML」「AI Platform Reliability Engineer」岗位，senior 级 $176,000–$333,500（DZone「AI Reliability Gap」2026）；AI SRE 全国中位 $178,000 / 范围 $135,000–$232,000（orbytjobs.ai 81 城市数据，2026-04）。
- **AI GTM Engineer 需求 +205% YoY**：2025 年岗位数从 1,400+ 翻倍至 3,000+（Apollo.io、Bloomberry）；薪资 $132,000–$241,000（中位 $176,000），AI 专项技能 +23% 薪资溢价（Apollo.io、Captivate Talent）；Clay 公司 2026-08 推出 Workflows 节点式编排层，直接对位 GTM Engineer 工具栈（clay.com/blog/introducing-workflows）。
- **SRE + AI 技能溢价**：SRE 岗位中 11.4% 明确要求新一代 AI 技能（AI Agents 6.1%、LLM 3.8%），带 AI 技能 SRE 中位 $170,000 vs 无 AI 技能 $142,700，溢价 $27,300（InterviewStack「SREs Now Keep AI Agents Reliable Too」2026，n=2,772 帖）；AIOps 市场 $8.91B（2024）→ $11.16B（2026）→ $32.56B（2029 预测），CAGR 30.7%（InterviewStack 引 AIOps 行业数据）。
- **AI 平台收敛**：n8n / Dify / LangGraph / Coze Studio 四平台横评（头条 2026）——n8n 48k+ stars、Dify 35k+ stars、LangGraph 31.2k stars；n8n 是「工作流自动化 + AI 节点」最成熟组合，Dify 是「LLMOps 可视化」最成熟组合，LangGraph 是「多 Agent 状态机」最成熟组合。

> 一句话判断：**前三期讲「哪些岗位热、如何裂解、如何落到生产链路」，第 4 期讲「生产链路之外，Agent 如何教会人、保得稳、卖得动」。** 后端/前端工程底盘恰好卡在「AI Reliability」（SRE 直接复用）和「AI GTM」（API/数据工程直接复用）两块——这是工程化落地的「最后一公里」，不写模型却决定 Agent 能否被市场接受。

### 1. AI Reliability Engineer（SRE + AI 特化，深化第 3 期 AgentOps）

- **定义**：专责「让模型服务在生产环境稳定、可恢复、可解释」——SLO 设计、token 路径监控、drift 检测、混沌工程、事故响应；区别于第 3 期 AgentOps（侧重 Agent 编排层），AI Reliability 更底层，直接对标 SRE / Production Engineering（Anthropic AIRE 团队）。
- **核心能力**：SLO/SLO 设计（LLM serving）、监控/可观测（OpenTelemetry/Prometheus/Grafana）、chaos engineering、drift 检测（output/score/tool-use 三类信号）、事故响应（on-call/incident review）、高可用（HA/灾备/多区域）、GPU/TPU 加速器运维、RDMA/InfiniBand 网络优化。

  3. 进阶：drift 检测三类信号（output/score/tool-use）+ chaos engineering（故障注入）+ 事故 runbook
  4. 项目：把 `e2-smart-customer-service` 升级为「生产级 AI 服务」（SLO + 监控 + 告警 + 事故响应）

### 2. AI GTM Engineer（工程化营收链路，新类别）

- **定义**：把 LLM/Agent 嵌入销售/市场/营收链路——线索富集、客户研究、ICP 评分、外呼编排、数据回流 CRM；区别于第 1 期 AI PM（定义产品）与第 3 期 AI 平台（搭平台），GTM Engineer 专责「让 AI 直接产生营收」，工程化能力直接对位收入指标（Clay 公司 2023 年发明该岗位名，2026 年岗位数 +205% YoY）。
- **核心能力**：API/数据工程（Python/SQL/JavaScript）、工作流自动化（n8n/Clay/Zapier/n8n）、prompt 工程（ICP 评分/客户研究/邮件草稿）、CRM 集成（Salesforce/HubSpot）、数据治理（enrichment/quality/lineage）、AI Agent 编排（Claygent/n8n AI Agent Node）、可观测（trace 每个 run 的成本/结果）。
- **薪资带宽（2026）**：US 中位 $176,000 / 范围 $132,000–$241,000（Apollo.io GTM Engineer Club）；AI 专项技能 +23% 薪资溢价（Captivate Talent 2025）；独立顾问 $150–$300/hr（Betts Recruiting）；SF 高端 $180,000–$300,000 / NY $130,000–$230,000（Betts Recruiting）；国内 30-60W（未交叉验证，基于数据工程 + AI 同带）。
- **学习路径**：

  3. 进阶：ICP 评分 Agent（1-100 分 + 理由）+ 客户研究 Agent（3 字段结构化输出）+ 数据治理（enrichment 优先级/去重/质量报告）
