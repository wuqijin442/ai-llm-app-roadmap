## 一、市场总盘（为什么「角色分化」比「岗位数量」更值得关注）

- **Agentic 岗位 90K 量级**：US 市场 Agentic AI 岗位 YoY +280%，90K 岗位，平均 $190K；同期传统 developer 岗位 -27.5%（FrontierNews / Stanford AI Index 2026）。
- **LinkedIn 2026 最快增长**：AI Engineer +143%（连续 2 年 #1）；AI Solutions Architect +109.3%；AI Product Manager +89.7%；Prompt Engineer +95.5–135.8%；Data Annotator / AI Trainer +154%；CAIO 采用率 11%（2023）→ 26%（2025）→ 76%（2026 中）（WhatsTheBigData、IBM CEO Study 2026、LinkedIn Jobs on the Rise）。
- **角色分化**：「AI Engineer」这个标签下实际是 5 个不同 reqs（Applied AI / ML Eng / MLOps / Applied AI / Prompt Eng），增速各不相同（FutureProofing.dev、Index.dev）。
- **企业级 AI 缺口**：LinkedIn Q1 2026 报告显示 AI 相关岗位 +187% YoY，合格候选人供给仅 +34%；senior AI 岗位平均填补时长 94 天，是普通软件工程的 2 倍（CRM Curator 2026）。
- **国内应用层爆发**：百度/阿里/字节/美团合计 >17,000 个 AI 岗位，AI 占比 50-90%；应用层（Agent/RAG/Prompt）门槛相对低、需求量最大，部分套壳岗位有泡沫化风险（CSDN 163919604 综合脉脉/猎聘/智联/Boss 2025-2026）。
- **安全侧新瓶颈**：MCP 协议漏洞（工具毒化 / 运行时注入 / 内存注入 / 影子工具）已落地为真实攻击面；AI 安全工程师 $152K–$210K，MCP/Agent 协议审计师 $130K–$175K（几乎零供给）（artificialintelligencemax.com、practical-devsecops.com）。

> 一句话判断：**第 1 期讲「哪些岗位热」，第 2 期讲「热岗位如何裂解为可执行的角色细分」。** 后端/前端工程底盘正好落在「应用层 + 安全 + 集成」这三段最缺人的区间——而不是「模型训练」那段。

### 1. Agentic AI Architect / 多智能体架构师

- **定义**：设计「多 Agent 协作 + 工具编排 + 上下文路由 + 评测闭环」的整套 Agent 系统；区别于「写单个 Agent 的代码」，关注的是 Agent 之间的 handoff、memory、权限、可观测。
- **核心能力**：LangGraph/CrewAI/AutoGen 多 Agent 编排、A2A 协议（Agent-to-Agent）、MCP 服务治理、上下文窗口管理、成本模型、评测 harness、安全沙箱。
- **薪资带宽（2026）**：US $200K–$350K（FrontierNews）；Anthropic/OpenAI 头部 $300K–$550K；国内 80-150 万（CSDN 163919604 推算）。
- **学习路径**（对齐本仓库）：
  1. `docs/05-Agent智能体与Harness.md`（主线）
  2. `projects/01-practice/p3-simple-agent` → `projects/02-enterprise/e2-smart-customer-service`
  3. 进阶：多 Agent handoff（LangGraph StateGraph）、A2A 协议、MCP 服务注册中心
  4. 项目：把 e2 的「客服 Agent」升级为「路由 Agent + 检索 Agent + 执行 Agent」三 Agent 协作
- **对标项目/企业**：`langchain-ai/langgraph`、`crewAIInc/crewAI`、`microsoft/autogen`、Anthropic Agent SDK、OpenAI Agents SDK、Palantir（AIP）。
- **与 docs 衔接**：`docs/05` 第 4 节（Harness 6 组件）+ `docs/09`（多租户/合规视角）。
- **转岗适配度**：5/5（后端工程底盘 + 架构经验，直接对标）
- **来源**：frontiernews.ai、pmdw9gqd5at4.whatsthebigdata.com、llmhire.com
