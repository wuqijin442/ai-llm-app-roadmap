## 一、市场总盘（为什么现在布局）

- **AI 人才缺口 3:1**：全球 1.6M+ AI 岗位开放 vs 51.8 万合格工程师，供需比 3.2:1（LLMHire，2026-04）。
- **AI 薪资年涨 38%**，且越高阶越陡：AI Agent/编排 $185K→$238K（+28.6%）、LLM 微调 $195K→$245K（+25.6%）、MLOps $172K→$215K（+25.0%）（LLMHire）。
- **AI Agent/编排岗位**：占全部 AI 招聘的 22%，同比 +142%（LLMHire）；国内 AI 智能体开发人才需求同比 +244%（CSDN 综合脉脉/猎聘/智联/Boss，见 CSDN blog 163919604）。
- **AI 技能薪资溢价 56%**：同岗位有 AI 技能 vs 无 AI 技能，平均薪资差 56%（一年前仅 25%）；AI 相关岗位整体平均溢价 23%（PwC Global AI Jobs Barometer 2026，bitsfrombytes.com 汇总）。
- **国内**：AI 应用开发类岗位需求同比 +500%+，大模型应用开发人才缺口 >50 万（智联/猎聘/51CTO，见 toutiao a7677513688902926886）。
- **FDE（Forward Deployed Engineer）**：2026 年最稀缺的落地型岗位，需求同比 +700–800%，中位总包 $238K–$450K（yochana / neuronhire / getperspective）。
- **企业级 AI Agent 落地**：Gartner 预测 2026 年底 40% 企业应用嵌入 Agent（2025 不足 5%）；79% 企业已采用、仅 11% 在生产环境运行（saasultra）；2027 40%+ 项目取消预警（ai.sitebard.com）；平均 ROI 171%。

> 一句话判断：**模型在贬值，Harness 与工程落地在升值。** 后端/前端工程底盘恰好卡在「最稀缺」那段——AI 应用 ≈ 一个会调 LLM 的后端服务，工程化能力（API/鉴权/限流/异步/容器化/部署/可观测）就是杠杆。

### 1. AI Agent Developer / 智能体开发工程师

- **定义**：基于 LLM 构建能自主规划、调用工具、多步执行任务的系统；2026 年 AI 工程需求最大、增速最快的方向（+142%）。
- **核心能力**：ReAct/Plan-and-Execute、工具层、状态与记忆、失败重试与续跑（Harness）、评测（evals）、MCP、可观测。
- **薪资带宽（2026）**：US $185K–$238K（中位，+28.6%）；国内 1-2 年 28-40K/月，3 年 80-120 万（toutiao）。
- **学习路径**（对齐本仓库）：
  1. `docs/02` → `docs/03`（Prompt 基础 + 工具调用）
  2. `docs/05`（Agent + Harness，本仓库主线）
  3. `projects/01-practice/p3-simple-agent` → `projects/02-enterprise/e2-smart-customer-service`
  4. 进阶：MCP Server 自研、LangGraph 状态机、长任务续跑（checkpoint + resume）
- **对标项目/企业**：`microsoft/ai-agents-for-beginners`（73.3k★，18 课，已本地全量编译通过）、`ageerle/ruoyi-ai`（5.7k★，Java 企业 Agent 框架）、Anthropic Agent SDK / OpenAI Agents SDK。
- **与 docs 衔接**：`docs/05-Agent智能体与Harness.md` 第 4 节（Harness 6 组件）直接对应本岗核心。
- **转岗适配度**：5/5（工程底盘直接复用，Agent + Harness 是本仓库主线）
- **来源**：llmhire.com、getperspective.ai、jobsbyculture.com、toutiao a7664546979308978707

### 2. LLM Application Developer / 大模型应用开发工程师

- **定义**：把 LLM 能力封装成 API/服务，接入业务系统（RAG + Agent + 工具）；国内需求量最大的 AI 工程岗。
- **核心能力**：Python/TypeScript、FastAPI、向量库（Chroma/Milvus/PGVector）、RAG 全链路、LangChain/LlamaIndex、Docker/K8s、评测与成本。
- **薪资带宽（2026）**：国内应届 15-25K，1-2 年 28-40K，3-5 年 50-80 万；US $130K–$250K（aibusiness.vc / jobply.ai）。
- **学习路径**：
  1. `docs/04-RAG检索增强生成.md`（第一刚需）
  2. `projects/01-practice/p2-rag-docs-qa` → `projects/02-enterprise/e1-enterprise-kb`
  3. `docs/06-模型微调与部署工程化.md`（vLLM + LoRA 了解即可）
  4. 进阶：混合检索 + 重排 + 评测闭环（recall@k / MRR / faithfulness）
- **对标项目/企业**：`chatchat-space/Langchain-Chatchat`（38.6k★）、`1Panel-dev/MaxKB`（22.6k★）、JPMorgan / Walmart（有专职 Prompt/RAG 团队，jobply.ai）。
- **与 docs 衔接**：`docs/04` + `docs/09-企业级落地范式.md`（第 5 节评测体系）。
- **转岗适配度**：5/5（后端工程底盘 + RAG 全链路即可快速补齐）

### 4. Prompt Engineer / 提示词工程师

- **定义**：设计并迭代能让 LLM 稳定产出高质量、合规、可控输出的「输入-输出契约」；2026 年需求 +135.8%（aibusiness.vc），US 岗位 +777%（signalhire）。
- **⚠️ 反转信号**：ML/AI Work（2026-08）将 Prompt Engineer 评为「hype trap」——316 搜索/帖（过度追捧）、需求 -19% YoY、1800+ 岗位中仅 3 个 titled "Prompt Engineer"。纯 Prompt 岗正在被 AI Engineer / LLM Engineer 吸收，「Prompt 技能是基线，不再是专长」（jobsbyculture.com 2026-08）。
- **核心能力**：结构化任务拆解、Few-shot/CoT、评测（A/B）、幻觉抑制、工具调用编排、领域语言（金融/法律/医疗）。
- **薪资带宽（2026）**：US $101K–$192K（中位 $136K，+135.8%）；国内一线 2-5 万/月。
- **学习路径**：
  1. `docs/03-Prompt工程.md`（直接覆盖）
  2. `projects/01-practice/p4-prompt-lab`（Prompt 实验台）
  3. 进阶：Prompt 版本管理 + 回归测试 + 多轮对话状态
- **对标企业**：Anthropic、OpenAI（有专职 Prompt 团队，jobply.ai）、JPMorgan。
- **与 docs 衔接**：`docs/03` + `docs/05`（Harness 的 Prompt 部分）。
- **转岗适配度**：4/5（门槛低，但天花板取决于「评测 + 领域深度」）
- **来源**：aibusiness.vc、signalhire、jobply.ai

- **薪资带宽（2026）**：US 基础标注 $35K–$100K，编码向 RLHF $50-65/hr，资深 $120K–$180K；国内 L3 级 15-40K/月（besthub.dev）。
- **学习路径**：
  1. `docs/03-Prompt工程.md`（基础）

  4. 差异化：选一个垂直领域（金融/法律/医疗/代码）做深度标注与评测
- **对标企业**：Scale AI、Appen、Surge AI、OpenAI、Google DeepMind（aireplacedmyjob.com）。
- **与 docs 衔接**：`docs/09` 第 5 节（评测体系）+ `docs/04`（RAG 评测）。
- **转岗适配度**：3/5（可作为兼职/副业，长期价值在「领域深度 + 评测能力」）

- **薪资带宽（2026）**：US $140K–$230K（+62%）；UK €60K–€120K；国内 AI 合规专员 1.5-3 万/月，资深 30 万+（toutiao m.toutiao article/7610699978100539944）。
- **学习路径**：
