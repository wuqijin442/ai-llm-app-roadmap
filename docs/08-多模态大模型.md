# 08 · 多模态大模型（拓展方向）

> 2026 爆发点。作为进阶模块，不必早期投入，但要知道能做什么、怎么用。

## 1. 什么是多模态
模型能同时理解和生成 **文本 + 图像 + 音频 + 视频**。从「只能聊天」到「能看、能听、能画」。

## 2. 主流模型
| 类型 | 代表 | 场景 |
|---|---|---|
| 视觉语言(VLM) | GPT-4V、Qwen-VL、GLM-4V、LLaVA | 图文问答、图表理解、截图分析 |
| 语音 | Whisper(识别)、CosyVoice(合成) | 语音助手、会议转写 |
| 图像生成 | Stable Diffusion、FLUX | 营销图、设计稿 |
| 视频 | 可灵、Sora 类 | 短视频、解说 |

## 3. 实战项目思路
- 图文问答：上传储能设备截图/接线图 → 模型解读并回答。
- 文档图表抽取：把 PDF 里的曲线图转成数据 + 结论。
- 语音运维助手：现场语音 → 转写 → 查知识库 → 语音回复。

## 4. 与主线关系
多模态 = 在 RAG/Agent 基础上「把文本 IO 换成多模态 IO」。底层的 Harness、检索、工具调用逻辑完全复用。建议先吃透文本主线，再拓展多模态。

> 你已有 qwen3-vl 在 DGX 上，图文理解可直接本地试验，零成本。
