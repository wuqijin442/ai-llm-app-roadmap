# 02 · 大模型基础认知

> 目标：建立直觉，能选型、能对话、能判断「该不该用 LLM」。不推导数学。

## 1. 核心概念（必须说清）

| 概念 | 一句话 | 为什么重要 |
|---|---|---|
| Token | 模型处理文本的最小单位（中文约 1–2 字 = 1 token） | 计价、上下文窗口都按 token 算 |
| Embedding | 把文本映射成向量，语义相近→向量相近 | RAG 检索、相似度的基础 |
| 上下文窗口 | 模型一次能「看到」的最大 token 数 | 长文档需分块 / 压缩 |
| 预训练 | 在海量语料上学的「通识」 | 通用能力来源 |
| 微调(SFT) | 用特定数据再训练，适配垂直任务 | 垂直领域/风格定制 |
| 推理 | 模型接收输入、产出输出的过程 | 你调用 API 就是在「推理」 |
| 幻觉 | 模型一本正经编假内容 | RAG / 引用来源是用来压制的 |

## 2. 两类模型：公有 API vs 开源本地

| 维度 | 公有 API（OpenAI/通义/DeepSeek/GLM） | 开源本地（Qwen/Llama/GLM） |
|---|---|---|
| 上手 | 极快，注册拿 Key 即用 | 需部署，Ollama 已极大简化 |
| 成本 | 按 token 计费，量大贵 | 一次性算力，推理免费 |
| 数据隐私 | 数据出公网 | 可完全内网，适合企业敏感数据 |
| 可控性 | 黑盒，不能改模型 | 可微调、可量化、可换 |
| 适用 | 对外产品、快速验证 | 内网知识库、私有化、降本 |

> 你的现状：DGX + Ollama 已能跑 Qwen / DeepSeek / qwen3-vl，**练习阶段全部走本地**，零成本。

## 3. 2026 主流模型选型速查

| 模型 | 定位 | 适合场景 |
|---|---|---|
| GPT-4o / o 系列 | 综合最强，贵 | 复杂推理、多模态 |
| Claude | 长文本、代码、安全对齐好 | Agent、长文档 |
| DeepSeek | 性价比极高，推理强 | 中文业务、成本敏感 |
| 通义千问 Qwen | 中文强、生态全 | 国内企业、多模态 Qwen-VL |
| GLM（智谱） | 中文均衡 | 企业应用 |
| Llama 3 / Qwen 开源 | 可本地部署 | 私有化、微调练习 |

## 4. 怎么判断「该不该上 LLM」
- ✅ 非确定性、需理解语义、需生成自然语言：客服、摘要、抽取、问答。
- ❌ 确定性强、规则清晰、低延迟高并发：用传统代码/规则引擎更稳更省。
- LLM 是「不确定性组件」，必须配兜底、校验、日志。
