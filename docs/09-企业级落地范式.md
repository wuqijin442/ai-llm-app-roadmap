# 09 · 企业级落地范式

> 从「能跑 demo」到「能交付系统」的关键跨越。这是工程背景转岗者最大的优势区。

## 1. 标准落地流程
```
需求拆解 → 技术选型 → 数据准备 → 原型验证 → 工程化 → 评测 → 上线 → 运维迭代
```

## 2. 需求拆解（先问清）
- 是真需要 LLM，还是规则引擎更合适？（见 `docs/02` 判断表）
- 准确率底线多少？可接受的幻觉率？有无人工复核环节？
- 数据是否敏感（是否需要私有化）？
- 并发 / 延迟 / 成本预算？

## 3. 技术选型清单
- 模型：公有 API（快） vs 开源本地（隐私/降本）。
- 框架：LangChain/LangGraph（自研） vs Dify（低代码）。
- 存储：向量库选型（Milvus/PGVector）。
- 服务：FastAPI + Docker + 监控。

## 4. 安全与合规（企业必考）
- **数据不出域**：敏感业务走私有化部署。
- **权限/审批**：Agent 改数据、发消息前需人工确认（Harness 的 safety 层）。
- **防注入**：用户输入不当指令（见 `docs/03`）。
- **审计日志**：每次决策可追溯。

## 5. 评测体系（别凭感觉）
- 建 **评测集**（50–200 条真实问答对）。
- 指标：准确率、召回率、格式合规率、幻觉率、延迟、成本/次。
- 每次改 Prompt/检索策略都跑评测，量化提升。

## 6. 成本工程
- 缓存高频问答（Redis）。
- 简单任务用小模型，复杂任务才上大模型。
- 长文本用压缩/摘要，省 token。

## 6b. Token 经济学（2026 新增，企业第一成本项）

> 来源：W36 周报 P1 修订 + 第 6 期 AI Agent Cost Engineer 条目（zylos.ai 2026-05 引 Rebase State of AI 2025 / app-lab.ai / zdnetinside.com）。

- **成本结构**（2026）：
  - 企业 AI 月均支出 **$85,521**（YoY +36%）
  - 模型 API 占 AI 预算 **30–40%**
  - Token 经济学成**第一成本项**（agentic 工作流 token 消耗可非线性增长）
- **四大降本杠杆**（叠加 70–85%）：
  1. **Prompt Caching**（exact / semantic / provider-native）：60–90% 命中
  2. **Model Routing**（cascade routing / quality gate）：40–70% 降本
  3. **Batch API**（离线任务异步批处理）：50–70% 降本
  4. **自托管**（7B 模型 50%+ GPU 利用率盈亏平衡 / 13B 10%+）：长期降本
- **成本归因**：per-trace / per-user / per-agent，接入 Langfuse / OTel GenAI。
- **架构决策**：量大选本地（vLLM/SGLang/TGI），量小选 API；简单任务用小模型（DeepSeek/Qwen），复杂推理才上 GPT/Claude。
- **对标**：`openai/openai-python`（31.5k★，Prompt Caching + Batch API 基础）、`stanfordnlp/dspy`（37.7k★，prompt 编译优化）（均已克隆）。
- **岗位映射**：AI Agent Cost Engineer（US $140K–$250K）/ AI Platform Engineer（成本分摊 per-trace）。

## 7. 交付checklist（面试讲这个）
✅ 需求边界清晰 ✅ 有评测集与基线 ✅ 失败重试/续跑 ✅ 工具有审批 ✅ 日志可观测 ✅ 成本可控 ✅ 可部署可演示
