## 阶段拆解

### 阶段 0 · 基础认知（1–2 周）
- **学什么**：Token / Embedding / 上下文窗口 / 预训练·微调·推理区别；主流模型选型（GPT / Claude / 通义千问 / DeepSeek / GLM / Llama / Qwen）。
- **交付物**：一篇《主流模型选型对比》笔记（存 `docs/02`）。
- **校正**：别一上来啃论文，先建立「模型怎么工作」的直觉。

### 阶段 1 · 开发基础 / API 调用（2–3 周）
- **学什么**：Python 进阶、用 Python 调 Chat Completion、流式输出（SSE）、Function Call、错误处理、.env 管理 Key。
- **交付物**：`projects/01-practice/p1-chatbot-cli`（流式对话机器人）。
- **校正**：后端同学此阶段几乎无门槛，1 周可出第一个应用。

### 阶段 2 · Prompt 工程（2 周）
- **学什么**：Zero/Few-shot、CoT、自我一致性、格式约束（JSON/Markdown）、角色设定、防注入。
- **交付物**：`projects/01-practice/p4-prompt-lab` + 10+ 模板。
- **校正**：2026 的 Prompt 不是模板堆砌，是「结构化任务拆解 + 输出约束」。

### 阶段 3 · RAG 检索增强（6 周，核心）
- **学什么**：文档解析 → 分块 → Embedding → 向量库 → 检索 → 拼接 → 生成；混合检索、重排、上下文压缩、多轮记忆、幻觉检测。
- **交付物**：`projects/01-practice/p2-rag-docs-qa` → 进阶到 `projects/02-enterprise/e1-enterprise-kb`。
- **校正**：企业落地第一刚需 + 面试最高频，必须做深。

### 阶段 4 · Agent 与 Harness（4–6 周，进阶）
- **学什么**：ReAct 循环、工具调用、记忆、规划反思、MCP 协议、LangGraph、Harness 工程（运行/治理层）。
- **交付物**：`projects/01-practice/p3-simple-agent` → `e2-smart-customer-service`。
- **校正**：2026 真正拉开差距的是「模型外的系统设计」。

### 阶段 5 · 微调 / 部署 / 面试（2–3 月）
- **学什么**：LoRA/PEFT 流程、量化、vLLM 部署、FastAPI 服务化、Docker、评测、作品集、面试题。
- **交付物**：1 个私有化部署服务 + 完整作品集 + 模拟面试。
- **校正**：微调「了解流程、能跑 demo」即可，不必精通炼丹；部署是工程岗加分项。
