# 10 · 面试求职冲刺

> 转岗成败在「作品集 + 表达」，不在刷题量。

## 1. 岗位 JD 解析（大模型应用开发常见要求）
- 熟练 Python；懂 LLM 原理（Token/上下文/RAG/Agent）。
- 用过 LangChain/LlamaIndex；做过 RAG / Agent 项目。
- 有向量库、FastAPI、Docker 经验。
- 加分：私有化部署(vLLM)、微调(LoRA)、可观测、成本优化。

## 2. 简历包装（用结果说话）
- 每个项目写：**业务痛点 → 技术选型 → 核心流程 → 量化效果**。
  - 例：「搭建储能电价政策知识库，RAG + 混合检索 + 重排，问答准确率 92%，替代人工查文档 70% 工时。」
- 突出工程化：限流、重试、续跑、观测、成本。

## 3. 高频面试题（按层）
- **基础**：Transformer 自注意力计算？位置编码作用？预训练 vs 微调？
- **核心**：RAG 原理与优化？LoRA 原理？Agent ReAct 循环？模型量化？
- **工程**：vLLM 为何快？FastAPI 怎么做流式(SSE)？Docker 部署流程？MCP 是什么？
- **前沿**：Harness 是什么？多模态怎么融合？MoE 架构？
- **场景**：「让用户上传 PDF 问答，怎么设计？」「Agent 执行到一半崩了怎么办？」

## 4. 作品集模板（每个项目一页）
```
项目名 / 角色 / 周期
- 业务痛点
- 技术选型（模型、框架、向量库、部署）
- 核心流程（配架构图）
- 量化效果（准确率/成本/延迟）
- 难点与解决（重试、续跑、幻觉抑制）
- 代码地址 + 演示
```

## 5. 模拟面试
- 准备 1 分钟自我介绍（突出「工程底盘 + AI 应用落地」）。
- 选 2 个项目做深度复盘（能讲清每个技术选择的 why）。
- 刷大厂真题（算法 + 技术问答）各 10 道。

## 6. 我的视角建议
面试别只讲「模型答得准」，要讲「系统设计稳」：失败重试、长任务续跑、工具审批、日志观测、成本可控——这正是 Harness 思维，也是你相对纯算法同学的差point。
