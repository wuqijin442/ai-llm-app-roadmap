# 07 · 技术栈与开发框架

> 一张「该装什么、干什么用」的清单。后端同学看这表会有强烈熟悉感。

## 1. 语言与 Web
| 技术 | 用途 | 你已有的基础 |
|---|---|---|
| Python | 主力开发语言 | 需补进阶（类/异常/第三方库） |
| FastAPI | AI 服务 Web 框架（对标 Spring Boot） | 后端思维直接迁移 |
| Node.js / Go | 高性能网关/流式 | 可选 |
| Redis | 会话缓存、限流、问答缓存 | 后端老技能 |

## 2. 应用开发框架
- **LangChain**：最主流，组件全（Document/Loader/Splitter/Embeddings/VectorStore/Chain）。岗位需求最大。
- **LlamaIndex**：RAG 向更强，轻量。
- **LangGraph**：把 Agent 编排成「图」，适合多步骤/有状态流程。

## 3. 向量数据库（RAG 核心，必学）
- Milvus（生产首选）、Chroma（原型）、FAISS（本地）、PGVector（Postgres 扩展，后端友好）。
- 必会：数据入库、相似度检索、索引优化、增删改查。

## 4. 模型与推理
- 开源部署：Ollama（你已有）、vLLM（高性能）、Text Generation WebUI。
- Embedding：BGE / m3e / OpenAI text-embedding-3。

## 5. 可观测与工程化
- **LangSmith / Phoenix**：追踪 LLM 调用链、调试、评测。
- **日志/监控**：把每次调用（入参、输出、耗时、token、成本）落库，这是 Harness 的基础。
- **Docker / Compose**：一键起整套（模型 + 向量库 + 服务）。

## 6. 可视化编排（快速验证用，非代码）
- Dify、AnythingLLM、Coze：拖拽搭 RAG / Agent，适合给业务方演示、验证想法，再决定是否自研。

## 7. 我的选型建议（性价比路线）
练习期：Python + LangChain + Chroma + Ollama（本地，零成本）。
实战期：FastAPI + LangGraph + Milvus/PGVector + vLLM（私有化）+ Phoenix（观测）。
