## 二、本周热点趋势（从 29 个岗位数据中提炼）

### 2.1 趋势一：薪资天花板继续向「基础设施 + 安全 + 推理」上移
- **数据**：本周薪资最高的岗位全部落在「基础设施/安全/推理」三簇——AI Infrastructure $246,150 中位（agenticcareers.co 2026-09，全 AI 岗类第一）、MCP Orchestration Staff total $380K–$550K（llmhire.com，全 AI 岗类第二高）、LLM Inference（NVIDIA Senior L4/L5 $184K–$356.5K，builtin.com）、AI Agent Security（Frontier Labs staff/principal $450K–$700K+，practical-devsecops.com）、Anthropic Model Evaluations $500K–$850K total（techncv.com）。
- **判断**：「会调 API」的岗位（Prompt/Trainer 基础向）继续被压价，「能搭算力底座、能保安全、能优化推理、能治理」的岗位（基础设施/安全/推理/平台/评测）在升值。这正是后端/前端工程底盘的杠杆区。
- **对转岗者的含义**：简历/作品集应突出「工程化落地 + 基础设施」而非「模型能力」——会写 K8s/GPU 编排/分布式/可观测/评测/成本看板/推理优化，比会调 Prompt 更值钱。

### 2.2 趋势二：MCP 成为「Agent 互操作」第一协议岗位（本周最重要认知更新）
- **数据**：MCP 已入 Linux Foundation Agentic AI Foundation（AAIF）——月 SDK 下载 97M、10,000+ 生产 server、Google/OpenAI/Microsoft/Amazon 全面采用（dev.to 2026）；咨询/系统集成商 MCP 岗位 +410%（llmhire.com 2026-04，160+ 公司追踪）；MCP Orchestration Staff/Principal total $380K–$550K（全 AI 岗类第二高）；MCP 经验「已成为 AI 工程面试最有区分度的筛选项之一」（secondtalent.com 2026）。
- **含义**：MCP 从「AI Integration 子项」裂解为独立岗位——server 开发 + 安全权限模型 + 工具 schema 设计 + A2A 互操作。MCP = Agent→工具（垂直集成）、A2A = Agent→Agent（水平集成），生产系统两者都要。
- **对转岗者的含义**：后端 API 设计 + OAuth/鉴权 + 分布式经验直接复用，补 MCP 规范 + 工具 schema 设计 + Agent 评测视角即可。本仓库已克隆 MCP 三件套（servers 89.9k★ / python-sdk 24.1k★ / typescript-sdk 13.3k★）并验证，「懂后端 + 懂协议 + 懂 Agent 行为」是 2026 互操作岗位核心组合。

### 2.3 趋势三：FDE（Forward Deployed Engineer）12 个月 +729%
- **数据**：FDE 岗位 12 个月增长 729%（Indeed 643→5,330，skai.io 2026）；OpenAI 2026-05 成立 Deployment 公司（$4B+ 19 家投资）+ 收购 Tomoro（~150 FDE）；FDE 现是 AI 最高薪通才岗位——total comp $215K（Palantir 中位）到 $1.2M+（Anthropic principal），equity 占 top 55–70%（getperspective.ai 2026-05，1,200 FDE 薪酬数据）；80% 企业应用已嵌入至少 1 个 AI Agent（Gartner，2024 仅 33%），但仅 31% 企业有 Agent 真正跑在生产（S&P/McKinsey）。
- **含义**：「80% 嵌入 / 31% 在生产」的差距 = FDE 岗位爆发。企业不缺 Agent 演示，缺「能把 Agent 跑进生产、对结果负责」的工程师。
- **对转岗者的含义**：后端/前端工程底盘（生产级编码 + 客户沟通 + 评测框架 + 可观测 + 问题分解 + 结果负责）恰好卡在 FDE 能力集。这是「工程化落地」的终极形态，也是本仓库 Harness 主线的直接岗位映射。

### 2.4 趋势四：评测基础设施成「Agent 质量」第一门槛（LLM Evaluation +210% YoY）
- **数据**：LLM Evaluation 岗位 YOY 帖量增长 210%（Q1 2025 vs Q1 2026，llmhire.com）、平均招聘周期 67 天（比 senior ML 慢 12 天）；「2026 核心工具栈：OpenTelemetry tracing + Langfuse/LangSmith trace 管理 + DeepEval 自动化离线评测 + Galileo/Arize 生产监控 + Ragas RAG 指标 + GitHub Actions CI/CD」（aidevdayindia.org 2026-05）；LLM-as-judge 未校准有 15–22% position bias；「离线评测 catch 已知失败模式 + 在线评测 catch 未知失败模式，两者都必要」（aidevdayindia.org 2026）。
- **含义**：「评测基础设施 + 生产漂移监控」从 QA 子项裂解为独立岗位——DeepEval（15+ 内建指标 + 幻觉/偏见/毒性检测）+ 回归套件工程化 + 离线/在线双轨是「Agent 能持续测」的核心杠杆。
- **对转岗者的含义**：后端测试经验直接复用，补 LLM 侧评测指标（hallucination/relevancy/contextual precision/toxicity/bias）+ LLM-as-judge 校准 + 统计素养（Cohen's kappa / Krippendorff's alpha）即可。本仓库已克隆 deepeval（18.1k★）/ ragas（15.5k★）/ langfuse（33.9k★）并验证。

### 2.5 趋势五：Token 经济学成第一成本项（Prompt Caching + Model Routing 叠加 70–85%）
- **数据**：企业 AI 月均支出 $85,521（YoY +36%）、模型 API + 实验占 AI 预算 30–40%（zylos.ai 2026-05 引 Rebase State of AI 2025）；**Prompt Caching 60–90% 缓存 token 节省 + Model Routing 40–70% 总支出节省 + 两者叠加常规 70–85% 成本降低**（zylos.ai 2026-05 引 Anthropic Prompt Caching 文档 + ProjectDiscovery 实践）；「Retrieval-based memory 砍 72% token with identical quality」「90% 的 agent 过度授权」（niteagent 2026）；H2 2026 预测：mid-market 企业推理 50%+ 在 open-weights 上完成（zylos.ai 2026-05）。
- **含义**：「AI Agent Cost Engineer」从「DevOps 附加项」裂解为独立岗位——cost per successful task 建模 + 路由决策器 + caching 命中率优化 + circuit breaker + cost attribution。
- **对转岗者的含义**：后端「成本/延迟优化」经验直接复用（Redis 缓存 → Prompt Caching、限流 → circuit breaker、监控 → cost attribution）。这是「工程能力杠杆」在 AI 成本侧的直接映射。

### 2.6 趋势六：记忆从 RAG 特性裂解为独立产品类目（五层记忆栈 + 晋升门控）
- **数据**：记忆已从 context engineering 中分离，成为独立产品类目，五个设计阵营（jacoblangvadnilsson.com 2026）；生产 Agent 五层记忆栈（turion.ai 2026）：Working（Redis 毫秒级）→ Short-term（Redis TTL）→ Long-term（Postgres）→ Semantic（向量 + BM25 + rerank <200ms）→ Episodic（ClickHouse <500ms）；**全量上下文 72.9% 准确率但 17s 延迟 + 26K token/对话，选择性记忆检索以 6pp 准确率换 91% 延迟降 + 90% token 省**（Mem0 State of AI Agent Memory，zylos.ai 2026-04）；**记忆晋升（session→user/tenant/global）是 Agent 架构最高危操作**（silent guardrail drift + precedent poisoning）；Mem0 60.7K stars / 380 contributors / 21 框架集成，LongMemEval 94.4 / LoCoMo 92.5（app-lab.ai 2026）。
- **含义**：「Context / AI Memory Engineer」从「RAG 工程子项」裂解为独立岗位——五层记忆栈 + 检索经济学 + 记忆晋升门控是长跑 Agent 的核心杠杆。
- **对转岗者的含义**：后端「数据建模 + 缓存 + 存储分层」经验直接复用（Redis → Working 层、Postgres → Long-term 层、向量库 → Semantic 层、ClickHouse → Episodic 层）。本仓库已克隆 mem0（64.7k★，记忆层品类第一）/ qdrant / pgvector / milvus 并验证。

## 三、岗位能力模型更新（六期沉淀的「能力雷达」）

把 29 个岗位的能力项按「工程能力杠杆」聚类，得到 6 个能力簇（适配度 5/5 的岗位全部落在前 4 簇）：

| 能力簇 | 核心技能 | 对标的 5/5 适配岗位（W36） | 工程底盘复用度 |
|---|---|---|---|
| **保 Agent（可靠性 + 推理优化）** | SLO 设计、drift 检测、混沌工程、vLLM/SGLang/TGI 三大引擎、KV Cache/量化/投机解码、TP/PP/DP 并行 | AI Reliability、LLM Inference（三大引擎特化） | 5/5（SRE/运维/性能工程经验直接复用） |
| **测 Agent（评测基础设施）** | DeepEval 15+ 指标、LLM-as-judge 校准（position bias 15–22%）、Ragas RAG 指标、CI/CD 集成、离线/在线双轨、A/B + 统计素养 | AI QA/Eval、AI Evaluation Ops、AI Agent Evaluation | 5/5（后端测试经验直接复用） |
| **架 Agent（平台 + 基础设施）** | K8s + GPU 编排、LLM Gateway、Ray 分布式计算、MLflow 实验追踪/模型注册/GenAI 评测、向量库运维、多租户/配额/成本分摊 | AI Platform、AI Infrastructure、Agent/RAG 基础设施 | 5/5（后端 DB/平台/API 集成/K8s 经验直接复用） |
| **管 Agent（治理 + 安全 + 记忆）** | EU AI Act/ISO 42001、MCP 安全 + 权限模型、五层记忆栈 + 晋升门控、tool poisoning 防御、prompt injection | MCP Engineer、AI Agent Security、AI Compliance、Context/Memory | 4-5/5（后端审计/鉴权/数据建模经验复用，补 AI 治理框架） |

> **核心结论**：后端/前端工程底盘（API/鉴权/限流/异步/容器化/部署/可观测/K8s/性能）恰好覆盖前 4 簇（保/测/架/管），这正是 AI 应用工程化「最稀缺」的区间。W36 新增的「AI 基础设施三件套」（第 9 期）进一步把「架 Agent」簇下沉到算力底座层——K8s + GPU 编排 + Ray 分布式计算是后端工程师直接复用的「工程能力杠杆」极致体现。转岗策略应是「用工程能力杠杆撬动 AI 应用层 + 基础设施层」，而非「和算法岗比模型」。
