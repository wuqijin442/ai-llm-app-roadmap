## 二、本周热点趋势（从 16 个岗位数据中提炼）

### 2.1 趋势一：「写 Agent」获国家职业认定，但市场几乎没有入门级（本周最重要政策信号）
- **数据**：2026-09-09 人社部公布第八批新职业，**「智能体开发员」正式成为国家新职业**；智联招聘 2026——AI 智能体开发人才需求同比 +244%、核心开发人才缺口超 500 万 / 供需比约 1:10、智能体市场规模 2026 年预计超 1,300 亿元。市场结构（agenticcareers.co 2026-09，1,707 开放岗位）：**Junior 仅 1% / Intern 1%，Executive 岗位数（51）超过 Junior + Intern 合计（37）**——「Agent 团队多为小团队、多为从其他团队调来资深工程师，没有专职培养 Junior 的岗位」；AI Agent Engineer 47 岗中位 $212,750。
- **判断**：政策端给职业「上户口」，市场端却关掉「练手岗」——转岗者的唯一门票是**作品集证明「能交付完整 Agent 系统」**。
- **对转岗者的含义**：第 13 期给出的能力模型是「**工程能力 70% + AI 技术栈 30%**」——后端/前端底盘恰好是那 70%，补 Python + RAG + Agent + Prompt + 评测即可；「5 页纸复盘」（场景价值 / 指标定义 / 局限与下一步，CSDN Dify 方法论）是最低成本的作品集形式。

### 2.2 趋势二：RAG 三部曲本周闭环——数据底座 → 应用框架 → 投毒防御（本周最重要技术纵深）
- **数据**：三期连发补齐 RAG 全栈——第 11 期 microsoft/graphrag 35.9k★（数据基础设施：实体/关系 + 社区摘要 + 多跳）、第 12 期 infiniflow/ragflow 90.3k★ + run-llama/llama_index 52.1k★（应用框架：深度文档理解 + 可视化工作流 + 内置评测）、第 15 期 RAG 投毒防御（**0.04% 语料投毒 → 98% 攻击成功率**（2026-02 分析）+ PoisonedRAG USENIX Security 2025 百万文档库 90% 成功率 + CVE-2026-33017 Langflow CVSS 9.8 + OWASP LLM08:2025）。
- **判断**：「RAG 系统的输出只取决于它检索到的语料，语料被投毒 = 系统被控制」（Rajai 复现：3 份投毒文档 + MacBook Pro 3 分钟）；且「RAG 投毒以语义对抗性散文投递 payload——没有 shellcode / 签名 / 崩溃转储，对现有安全栈基本不可见」（threatclaw.ai）。
- **对转岗者的含义**：RAG 岗位要求从「会调向量库」升级为「会建可推理的数据底座 + 会防数据投毒」——防御栈五层（溯源哈希 / 检索异常检测 / 多源佐证 / 人类在环 / 语义异常检测）是新增硬技能。

### 2.3 趋势三：工作流编排从「平台功能」裂解为独立岗位（2025 不存在 → 2026 +82%）
- **数据**：AI 工作流设计师 2026 招聘量同比 +82%（agent.csdn.net，推荐指数 5/5 技术人首选）；n8n 突破 10 万自托管实例、智能自动化市场 2030 年 $30B（secondtalent.com）；国内「智能体&Dify 开发工程师」JD 成片出现（1.1–2.2 万全栈 / 30–50K 深圳南山）；AI Workflow Automation Specialist US Entry $90K–$130K / Principal $260K–$350K+；对标仓库 langflow 154,605★（**超过 dify，本仓库历史第二高星**）+ coze-studio 21,574★（字节官方）。
- **判断**：「企业买了 AI 工具没人会用」催生新岗位——岗位本质是「RPA（不碰 AI）、Prompt 工程（不接系统）、Agent 开发（不进受控工作流）三者之间的中间地带」，而中间地带正是「大多数真实的、反复出现的 AI 价值所在」。
- **对转岗者的含义**：API 对接 / 限流 / 重试 / 异步 / 容器化经验直接复用，补「四平台矩阵（Coze/Dify/n8n/Langflow）+ 错误处理/幂等/死信队列 + LLM 集成」即可入场。

### 2.4 趋势四：AI 安全从「最佳实践」变「法定义务」+「国家职业技能」
- **数据**：EU AI Act **Article 55 对系统性风险 GPAI 模型强制红队测试**（2026-08-02 执法生效，罚则至 7% 全球营收）；LLM Red Teamer US $110K–$280K / Staff/Principal TC 最高 $700K+ / 国内 35–60 万（2026 增长最快 AI 安全细分，whatisthesalary.com）；AI 对齐评估 LLM Evaluation 帖量 +210% YoY / 平均招聘 67 天 / US $145K–$230K / 国内 AI 对齐岗校招总包 42 万 vs 传统测开 18 万（差 2.3 倍）；**人社部把「生成式人工智能系统测试员」纳入国家职业技能标准**（给证书、给补贴）。
- **判断**：红队（主动攻击找漏洞）+ 投毒防御（防数据供应链）+ 对齐评估（自证安全）三岗本期全部 5/5——「在坏人之前先把模型玩坏」和「证明模型不会被玩坏」是同一枚硬币的两面。
- **对转岗者的含义**：传统测开被 AI 替代（初级替代率 70%）的同时，AI 对齐评估成为「自动化剩余」最高的赛道——人类判断价值取向大模型自己做不了；后端补「Garak/Promptfoo/PyRIT + 统计素养（Cohen's kappa / Bradley-Terry）+ LLM-as-judge 校准」即可切入。

### 2.5 趋势五：传统岗 → AI 岗薪资溢价首次全面量化（+31.4% ~ +84.6%）
- **数据**：Lemon.io 2026-09——SRE 加 ML 技能 $130K → $240K（**+84.6%，全表最高**）、Cloud Engineer 转 AI/GPU Cloud +78.6%、Solutions Architect 转 AI SA +59.3%、传统 SW 转 AI Engineer +58.6%、传统 PM 转 AI PM +55.6%、LLM Engineer +38.7%、AI Application Developer +31.4%；AI 运维比传统运维高 20%–45%（国内一线 30–50K / 超算运维 70K+），被 CSDN 评为「**转型成本最低岗位**」。
- **判断**：「加 AI 技能到现有岗位」比「裸转全新岗位」溢价更高、路径更短——SRE + ML 是本周量化出的最优组合。
- **对转岗者的含义**：不必离开 EMS/储能行业——「懂行业 + 补 AI」比「懂 AI 再学行业」更快（第 14 期：71% AI PM 岗位不需要真正懂 AI 底层，企业找的是懂行业的人去用 AI）。

### 2.6 趋势六：A2A 补齐「agent→agent」，MCP + A2A 双协议格局确立
- **数据**：a2aproject/A2A 25.7k★（Google/Linux Foundation 托管，Agent 互操作协议品类 star 第一）；第 8 期 MCP（agent→tool，月 SDK 下载 97M）+ 第 10 期 A2A（agent→agent）构成互操作双协议；跨框架集成（LangGraph / CrewAI / ADK / Dify）+ agent 身份 / 权限 / 审计是 A2A 工程师核心能力。
- **判断**：多 Agent 系统从「单 Agent + 工具调用」升级为「多 Agent + 互操作协议」——垂直集成用 MCP、水平集成用 A2A，生产系统两者都要。
- **对转岗者的含义**：后端协议 / API 设计经验直接复用，本仓库已克隆 MCP 三件套 + A2A，「懂协议 + 懂后端 + 懂 Agent 行为」是互操作岗位核心组合。
